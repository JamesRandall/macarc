Holding the pointer still while the mouse is captured, on Wayland: the
pointer-constraints and relative-pointer protocols, which GTK has no API for.

The `*-protocol.c` and `*-client-protocol.h` files are generated by
wayland-scanner 1.24 from wayland-protocols 1.47's XML
(`/usr/share/wayland-protocols/unstable/pointer-constraints` and
`relative-pointer`):

    wayland-scanner client-header IN.xml NAME-client-protocol.h
    wayland-scanner private-code IN.xml NAME-protocol.c
